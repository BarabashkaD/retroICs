# Intel 8257 programmable DMA controller

## Function

Four-channel DMA controller: fixed or rotating priority, autoload on channel 2, TC and MARK outputs;
read, write and verify cycles.

## Pinout

`record.md`, DMA-36 (40-pin DIP).
