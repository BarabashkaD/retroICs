# Intel 8255A programmable peripheral interface

## Function

Three 8-bit ports (A, B, C) in mode 0 (basic input / output), mode 1 (strobed) or mode 2
(bidirectional port A), with bit set / reset on port C.

`record.md`, PPI-20 (40-pin DIP).
