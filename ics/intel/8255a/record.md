# Intel 8255A programmable peripheral interface: data sheet record

Data sheet items of the Intel 8255A (КР580ВВ55А), split from the RK86 record with their IDs.

## Sources

Sources: [C78] 8255A/8255A-5 data sheet, printed pp. 12-76..12-94 (PDF 584-602; the M8255A pages after it, PDF 603-605, were not used). [D8255] `Intel - 8255.pdf` (the copy kept in the radio-86rk clone): "8255A-5 Programmable Peripheral Interface", Intel order number 231308-004, September 1993, 24 pages (p. 1 footer, p. 24 revision history: "references to the 8255A are changed to 8255A-5", "specifications for the 8255A are removed"). It is a scan without a text layer; every page was read from renders. Its text is word for word the [C78] text; the differences are listed under "Edition differences" below (PPI-D1..D6). [UM83] has no 8255A data sheet and no 8255 application chapter; its only use here is the definition of tRV (A1-24, PDF p. 166). Pin names: STB, ACK, OBF, RD, WR, CS are active low; "OBF = 0" means the pin is low (buffer full). Figures are given as [C78] number / [D8255] number.

Not sources of behaviour: MAME, Emu80, Apogee, the Karabas core.

The documents cited here and their provenance: `datasheets/index.md` of this folder; the other source IDs: `docs/sources.md`.

## Notation

The original IDs are kept; new functions are numbered after them. What the section "Timing reference for 0.8.0 (Task 1 record)" establishes is cited as "Task 1 record, section a-d", not repeated: a in `ics/intel/8224/record.md`, b in `ics/intel/8257/record.md`, d in `ics/intel/8275/record.md`; c (the 8275 pins on the boards) is board wiring: `retroComputersDocs/computers/rk86/board.md` (pending). | PPI-1 | RESET | RESET is active high. "A high on this input clears the control register and all ports (A, B, C) are set to the input mode." "When the reset input goes high all ports will be set to the input mode (i.e., all 24 lines will be in the high impedance state). After the reset is removed the 8255A can remain in the input mode with no additional initialization required." "All Mask flip-flops [the INTE flip-flops] are automatically reset during mode selection and device Reset." Reset pulse ≥ 50 µs at or after power-on, later reset pulses ≥ 500 ns. Not given: the numeric value of the control register after reset; the word "mode 0" (the text says "the input mode"); the output latches and the IBF / OBF flip-flops after reset. The last two cannot be observed: every way to make a pin an output or to enter mode 1 / 2 goes through a mode set, which clears them (PPI-3). | [C78] 12-78 (PDF 586) RESET, 12-79 (PDF 587) "Mode Selection", 12-80 (PDF 588) Note, 12-93 (PDF 601) note 2; [D8255] pp. 3, 5, 6, 21 note 2 |
| PPI-2 | Mode 0 (basic input / output) | Two 8-bit ports (A, B) and two 4-bit ports (C upper PC7-PC4, C lower PC3-PC0), each input or output by control word bits D4 (A), D3 (C upper), D1 (B), D0 (C lower), 1 = input, 0 = output: 16 configurations, #0 = 80h (all outputs) .. #15 = 9Bh (all inputs); configuration # = D4 D3 D1 D0 as a binary number (table "MODE 0 Port Definition"). "Outputs are latched. Inputs are not latched." No handshake. Output pin change: tWB ≤ 350 ns after WR↑ ("WR = 1 to Output"). Input read: the peripheral data must be valid tIR ≥ 0 before RD↓ and held tHR ≥ 0 after RD↑ (waveform "MODE 0 (Basic Input)"), so the data bus shows the pins while RD is low. | [C78] 12-80 (PDF 588) "Mode 0 Basic Functional Definitions", waveforms; 12-81 (PDF 589) table, 12-81..12-83 control words #0..#15; 12-93 (PDF 601); [D8255] pp. 6-10, 20, 22 |
| PPI-3 | A mode set clears the outputs and the status | "All of the output registers, including the status flip-flops, will be reset whenever the mode is changed." "All Mask flip-flops are automatically reset during mode selection." So a mode-set write clears the port A, B, C output latches, IBF (→ 0), the OBF flip-flops (OBF pin → 1, empty) and INTE A, INTE B, INTE 1, INTE 2; INTR then evaluates to 0 (every INTR term contains an INTE). The text says "whenever the mode is changed": a mode-set write that repeats the current control word is not addressed (SILENT). | [C78] 12-79 (PDF 587), 12-80 (PDF 588) Note; [D8255] pp. 5, 6 |
| PPI-4 | Bit set / reset (BSR) | Control-port write with D7 = 0 (bit set / reset flag, "0 = active"); D6-D4 don't care; D3 D2 D1 = bit select B2 B1 B0 (PC0 = 000 .. PC7 = 111); D0 = 1 set, 0 reset. "Any of the eight bits of Port C can be Set or Reset using a single OUTput instruction." In modes 1 / 2 the INTE flip-flops are set and reset by BSR of their port C bit (PPI-30). "When Port C is being used as status/control for Port A or B, these bits can be set or reset by using the Bit Set/Reset operation just as if they were data output ports." What a BSR of a bit that is a handshake output (INTR, IBF, OBF) or a handshake input (STB, ACK, which hold the INTE) does to the pin: SILENT (the sentence above is the only text; it does not say whether the pin or only a latch changes). When the pin of an output bit changes after a BSR write: not given separately; tWB ("WR = 1 to Output") is the only output delay. | [C78] 12-79 (PDF 587) "Single Bit Set/Reset Feature", 12-80 (PDF 588) Fig. 5, text, "Interrupt Control Functions"; [D8255] pp. 5, 6, Fig. 7 |
| PPI-5 | Mode 1 strobed input (port A) | Control word 1 0 1 1 D3 X X X: D6 D5 = 01, D4 = 1 (input), D3 = direction of PC6, PC7 (1 = input). PC4 = STB A (input), PC5 = IBF A (output), PC3 = INTR A (output); INTE A is set / reset by BSR of PC4. STB: "A low on this input loads data into the input latch"; the data must be valid tPS ≥ 0 before and tPH ≥ 180 ns after the trailing (rising) edge of STB; STB width tST ≥ 500 ns. IBF: "set by STB input being low and is reset by the rising edge of the RD input": IBF↑ ≤ tSIB 300 ns after STB↓, IBF↓ ≤ tRIB 300 ns after RD↑. INTR: "set by the STB is a one, IBF is a one and INTE is a one. It is reset by the falling edge of RD": INTR↑ ≤ tSIT 300 ns after STB↑, INTR↓ ≤ tRIT 400 ns after RD↓. Port A input data latched ("Both inputs and outputs are latched"). | [C78] 12-83 (PDF 591) "Mode 1 Basic Functional Definitions", 12-84 (PDF 592) text, Fig. 6, Fig. 7, 12-93 (PDF 601); [D8255] pp. 10, 11 Fig. 8, 9, pp. 20, 21 |
| PPI-6 | Mode 1 strobed output (port A) | Control word 1 0 1 0 D3 X X X: D4 = 0 (output), D3 = direction of PC4, PC5. PC7 = OBF A (output), PC6 = ACK A (input), PC3 = INTR A; INTE A is set / reset by BSR of PC6. OBF: "will go low to indicate that the CPU has written data out to the specified port. The OBF F/F will be set by the rising edge of the WR input and reset by ACK input being low": OBF↓ ≤ tWOB 650 ns after WR↑, OBF↑ ≤ tAOB 350 ns after ACK↓; ACK width tAK ≥ 300 ns. INTR: "set when ACK is a one, OBF is a one, and INTE is a one. It is reset by the falling edge of WR": INTR↓ ≤ tWIT 850 ns after WR↓, INTR↑ ≤ tAIT 350 ns after ACK↑. With INTE set and no write since the mode set (OBF = 1, ACK = 1) the condition holds, so INTR is high. Port A output data: pins change ≤ tWB 350 ns after WR↑. The INTR↓ edge relative to WR↑ differs between the editions (PPI-D2, PPI-D3). | [C78] 12-85 (PDF 593) text, Fig. 8, Fig. 9, 12-93; [D8255] p. 12 Fig. 10, 11, pp. 20, 21 |

Output: PC1 = OBF B, PC2 = ACK B, PC0 = INTR B. INTE B is set / reset by BSR of PC2 in both directions. | PPI-8 | Mode 2 (bidirectional port A) | Group A only; control word 1 1 X X X D2 D1 D0 (D4, D3 don't care; D2 D1 D0 for group B as in mode 0 / 1; with group B in mode 0, D0 = direction of PC2-PC0). PC7 = OBF A, PC6 = ACK A, PC4 = STB A, PC5 = IBF A, PC3 = INTR A. "Both inputs and outputs are latched." Output: OBF goes low when the CPU writes port A (OBF↓ ≤ tWOB after WR↑, OBF↑ ≤ tAOB after ACK↓, Fig. 13 / 15). ## SILENT (PPI)

- PPI-1: the control register value after RESET (00h against "all ports input"); the word "mode 0"; the output latches and IBF / OBF after RESET (not observable). Searched [C78] 12-77..12-80, 12-93; [D8255] pp. 2-6, 21.
- PPI-3: a mode-set write that repeats the current control word ("whenever the mode is changed"). Searched [C78] 12-79, 12-80; [D8255] pp. 5, 6.
- PPI-4: the pin effect of BSR on a handshake bit (INTR, IBF, OBF outputs; STB, ACK positions hold INTE). Searched [C78] 12-79, 12-80, 12-84..12-89; [D8255] pp. 5, 6, 10-17.

## Assumptions checked

Model assumptions (PPI):

- The reset state is mode 0 with every port an input: confirmed for "every port an input / high impedance" ([C78] 12-78, 12-79; [D8255] pp. 3, 5); silent on the numeric control register value and on the word "mode 0" ("clears the control register" and "set to the input mode" are both printed; "the 8255A can remain in the input mode with no additional initialization"). The planned model value (mode 0, all inputs, = 9Bh) is the only reading that makes both sentences true for the pins; a literal 00h would be configuration #0 (all outputs). Latches and status flip-flops after reset cannot be observed (PPI-1).
- The output latches and the status flip-flops are cleared by a mode set: confirmed ([C78] 12-79, 12-80; [D8255] pp. 5, 6), with INTE cleared too. Silent for a mode-set write that repeats the current control word ("whenever the mode is changed").
- Port C byte writes in modes 1 / 2 change PC3-PC0 always and PC7-PC4 only while group A is in mode 0: silent. [C78] 12-89 / [D8255] p. 16 tell software to use BSR for free C upper outputs and allow a byte write for the free C lower bits ("as a threesome"); they do not say what a byte write does. The text applies to every combination with handshake bits, including group A mode 0 with group B mode 1, where the planned model writes C upper (PPI-29).
- The status words of modes 1 and 2: confirmed ([C78] 12-89 Fig. 15, 16; [D8255] p. 17 Fig. 17, 18); the model's bit layout agrees, including INTE read at PC4 / PC6 / PC2 and OBF read active low.
- A read of the control register returns FFh: silent. Only "Illegal Condition" and "No Read operation of the Control Word Register is allowed" are printed; the data bus state is not given ([C78] 12-77, 12-78; [D8255] p. 3).
- BSR of a port C bit that is a handshake output changes only the latch, the pin stays the handshake signal: silent, with a hint the other way: "When Port C is being used as status/control for Port A or B, these bits can be set or reset by using the Bit Set/Reset operation just as if they were data output ports" ([C78] 12-80; [D8255] p. 6). The sentence does not say whether the pin changes.
- A port A / B read in mode 1 output returns the output latch: silent ([C78] 12-78 port descriptions, 12-85; [D8255] pp. 3, 12).
- Board use, input pins (keyboard / tape PPI 8Ah, ROM disk PPI 90h): an input-mode pin is high impedance with ±10 µA input load current; no internal pull-up is specified; what a read of an undriven input returns (the ROM disk port A with no pull-ups) is silent ([C78] 12-79, 12-92; [D8255] pp. 5, 19).

## Differences (PPI)

- PPI-3 check (the model's check "wr(2'd3, 8'h80); wr ... FFh ...; wr(2'd3, 8'h80); chk(... latches not cleared)"): the second 80h repeats the mode already set, and the data sheet only says the outputs are reset "whenever the mode is changed" ([C78] 12-79; [D8255] p. 5). The check depends on the SILENT case; a check with a different second word (e.g. 9Bh then 80h, or 80h then 82h) would rest on printed text.
- PPI-5 check (status read `rd(2'd2, v); chk(v[5:3] == 3'b111, ...)` before the port A read) and the model (`rd_a`, `wr_a`, `rda_q`): they rest on the port's own address qualifying RD / WR, which the data sheet does not state (PPI-31). Not a contradiction; an unlisted SILENT item.
- PPI-6 check `chk(mid_pc[3] == 1'b0, "mode 1 output: intr during wr")` and the model (INTR low while WR to port A is low): they agree with the text and with [C78] Fig. 9; [D8255] Fig. 11 (1993) draws INTR still high during the WR pulse and falling after WR↑, and adds note 3 to tWIT (PPI-D2, PPI-D3). Both drawings are inside tWIT ≤ 850 ns.
- Model, group A mode 0 with group B mode 1: `io_out` takes PC3's direction from D0 (`cl_in`), which the group B mode 1 control word marks don't care (PPI-24, SILENT); and a port C byte write in that combination writes C upper, against the literal "Bits in C upper (PC7-PC4) must be individually accessed using the bit set/reset function" (PPI-29).
- The planned model's SILENT list says "the text says both 'clears the control register' and 'all ports set to the input mode'": confirmed, both sentences are on [C78] 12-78 / [D8255] p. 3; [C78] prints "(A, C, C)" (PPI-D1).
